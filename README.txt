# Kaashi Surprise Journey 💜

A multi-chapter, non-birthday, friendly surprise website.

Files:
- index.html
- style.css
- script.js

GitHub Pages:
1. Create/open a GitHub repository.
2. Upload all three files to the repository root.
3. Settings → Pages → Deploy from branch → main → /(root).
4. Save and open the generated Pages URL.

No external images are required. The site uses CSS effects and emoji/symbol visuals, so it works without an assets folder.


Updated build notes:
- First screen redesigned to match the supplied purple glass-door / moon / stars reference.
- Existing chapters, gifts, popups, effects and puzzle flow are retained.
- Screen transitions, taps, door opening and scrolling were smoothed.
- `kuch-iss-tarah.mp3` is included at the repository root and wired to the final moment.
- Upload/replace the files in the repository root; do not put the MP3 inside an assets folder.
